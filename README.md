# StudyPomo 讀書番茄鐘

資工所備考用的番茄鐘＋讀書紀錄網頁。


## 1. 目的與使用者
- 使用者：我自己（資訊系大四，準備資工所筆試），晚上在電腦或手機瀏覽器上使用。
- 要解決的問題：讀書時容易分心，也不知道每週實際讀了多少、各科分配是否平均。
- 目標：用番茄鐘幫助專注，並自動把每一輪專注時間記錄到科目底下，用統計看出每週是否達到讀書目標。

## 2. 技術限制
- 單一 `index.html`，CSS、JavaScript 寫在檔案內，不使用後端。
- 資料存在瀏覽器 localStorage，重新整理或關掉分頁後資料仍在。
- 可直接以 GitHub Pages 公開，電腦與手機（寬度 360px 以上）都能操作。

## 3. 功能需求

### 3.1 番茄鐘計時器
| 項目 | 規格 |
|---|---|
| 模式 | 專注、短休息、長休息 三種 |
| 預設長度 | 專注 50 分、短休息 10 分、長休息 20 分；每 4 輪專注後進入長休息 |
| 自訂 | 以上四個數字都可在「設定」修改（專注 1–180 分、休息 1–60 分、間隔 2–8 輪） |
| 控制按鈕 | 開始／暫停、跳過（休息時可直接回到專注）、結束（提前結束本輪） |
| 顯示 | 大字倒數 mm:ss、圓形進度環、目前模式、第幾輪 |
| 計時精準度 | 以「結束時間點」計算剩餘時間，切到其他分頁或手機螢幕關閉也不會跑慢 |
| 結束提示 | 播放提示音；瀏覽器分頁標題顯示倒數；若使用者允許，跳出系統通知 |
| 重新整理 | 計時中重新整理頁面，計時狀態會保留 |
| 快捷鍵 | 空白鍵＝開始／暫停 |

### 3.2 科目管理
- 預設六科：線性代數、離散數學、資料結構、演算法、作業系統、計算機組織，每科有不同顏色。
- 可新增科目、刪除科目。刪除後歷史紀錄保留、仍顯示原本科目名稱。
- 開始專注前要選科目；計時中不能切換科目。

### 3.3 讀書紀錄
- 一輪專注完整結束 → 自動新增一筆紀錄（科目、開始時間、分鐘數）。
- 提前按「結束」→ 詢問是否記錄已讀的分鐘數（滿 1 分鐘才可記錄）。
- 補登：可手動新增一筆紀錄（科目、日期、分鐘數），用在沒開計時器讀書時。
- 每筆紀錄可刪除（刪除前確認）。

### 3.4 統計
| 區塊 | 內容 |
|---|---|
| 今日各科時數 | 今天每一科讀了多久，用橫條顯示，並有今日總計 |
| 本週每日長條圖 | 週一到週日，每天一根長條，依科目分色堆疊，下方顯示時數 |
| 每週目標進度 | 預設每週目標 24 小時（可在設定修改），顯示已讀時數、百分比與進度條 |
| 歷史紀錄列表 | 最新的在最上面，顯示日期時間、科目、分鐘數、刪除按鈕 |

### 3.5 其他
- 深色主題為預設，可切換淺色。
- 資料可「匯出 CSV」，方便備份或貼到試算表。

## 4. 畫面配置
- 電腦版：左邊計時器卡片，右邊統計（今日、本週、目標），下方歷史紀錄。
- 手機版：由上而下依序為 計時器 → 目標進度 → 今日 → 本週圖表 → 歷史紀錄。

## 5. 驗收標準
1. 把專注時間設成 1 分鐘，按開始，1 分鐘後會響、會自動多一筆紀錄，今日、本週統計同步更新。
2. 計時中重新整理，倒數繼續、不歸零。
3. 提前結束時會詢問是否記錄，選「是」後紀錄分鐘數正確。
4. 每 4 輪專注後進入長休息。
5. 新增、刪除科目與紀錄都能正常運作，重新整理後資料還在。
6. 手機寬度下版面不會跑掉、按鈕可以點。
